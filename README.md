# 牧羊人與羊群 3D(sheepflock3d)

> 尋羊(路加福音 15)+ 集羊(約翰福音 10:3 按著名叫自己的羊)+ 護羊(撒母耳記上 17 大衛打獅熊)。
> 2026-08-11 換皮自 davidbeasts3d(護羊之戰);TSUM 圓萌造型(0811 使用者點名:牧人與羊都要可愛)。
> ★ 2026-08-12:**B 案完成——羊圈與「尋羊記」(GPS 抓寶版)互通了**,並加了 🗺 真實地標任務。

## 玩法

- **🐑 牧場漫遊・尋羊**:曠野裡的迷羊會咩咩叫(妹妹的聲音)+亮光柱,走過去尋回(路15:5 語音),
  取名字(約10:3)——每一隻羊基因長相都不同(毛色×斑紋×耳型×眼神×天賦配飾×體型)。
  取好名的羊進「羊圈圖鑑」,伴行的羊皮克敏式跟在牧人身後(最多 5 隻)。
  沒帶出門的羊會在東側石砌羊圈裡低頭吃草——看得到自己的收藏。
- **🗺 走在真實地圖上(0811 新增)**:首頁「牧場漫遊的地面」三選一——
  🌾 伯利恆曠野(預設,離線也能玩)/ 🗺 我家附近的真實地圖(需開定位+網路)/ 🧪 台北測試地圖(不用開定位)。
  選真實地圖時,牧人和羊群走在**你所在位置的真實街道**上(底圖與尋羊記同一份),
  迷羊散在 35~110 公尺外的街區,HUD 顯示「離迷羊距離」,循著金色光柱走過去(Shift 快跑)。
  ⚠ 拿不到定位或沒網路 → 自動退回曠野牧場照玩,不會卡住。
- **護羊之戰 / 與獸纏鬥 / 牧場練習**:davidbeasts3d 原班戰鬥(獅/熊 ×1~3、七陣容、
  紅色撲擊預告、聖靈金光、蜂蜜補血)+**出戰羊支援**(最多 3 隻,羊永遠不會死):
  - 🔔 鈴鐺羊:定時搖鈴,野獸分神(撲擊預告取消、節奏延後)
  - 🧣 絨毛羊:替牧人擋下一次重擊(20 秒冷卻)
  - 🍯 快腿羊:野地的蜂蜜更常出現
  - 🎵 詩歌羊:牧人勇氣緩慢恢復
- **羊圈圖鑑**:蒐集牆(每隻都是**會動的 3D 小羊**:轉圈+踏步+小蹦跳)+伴行/出戰選擇+匯出/匯入 JSON。
  遊戲中隨時可開:畫面左上「🐑 羊圈」鈕 / 側欄「🐑 我的羊圈」/ 鍵盤 **B**;
  漫遊中改了伴行名單,關掉視窗就立即換班。

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 走位 | W/A/S/D | 方向鍵 |
| 快跑 | 按住 Shift | 衝刺鈕 |
| 視角(5 檔) | V | 視角鈕 |
| 羊圈圖鑑 | B | 🐑 羊圈鈕 |
| 暫停 | Esc / P | 暫停鈕 |
| 輕拳 / 重拳 / 格擋(戰鬥) | J / K / C | 對應鈕 |

視角 5 檔輪流:跟隨視角 → **側身跟隨**(看得到牧人側身、手上的竿與腰間的杖)→ 側面轉播 → 高空俯瞰(真實地圖看街廓最好用)→ 第一人稱。

## 🗺 真實地標的羊(0812 新增)

選了真實地圖之後,**走進真的公園、學校或球場**,那個地方會有一隻**唱詩的羊**在等你
(淡青色光柱,和一般迷羊的金色不一樣;訊息會直接寫出地名,例如「你走到『大安公園』了!」)。
每個地方**一天一隻**,隔天再去還有。羊圈裡會記著牠是在哪裡遇見的。

- 地標從哪來:內建**台北一帶的公開地標包**(257 個,不連外);走出這個範圍才會查一次
  「這一帶有哪些公園」,查到的結果**只存在你這支手機裡**。
- 首頁「**真實地標的羊**」可以關掉(關了=只用內建地標,完全不連外)。
- 🔒 羊圈**只記地方的名字,不記經緯度,也不會上傳**。

## 🐑 羊圈和「尋羊記」互通(0812 完成)

兩個網站在**不同網址**,所以手機上的羊圈和電腦上的羊圈是**各自存的**(瀏覽器的規則)。
把羊搬過去有兩條路,羊圈(🐑)視窗裡都有:

| 怎麼搬 | 適合 | 怎麼做 |
|---|---|---|
| ☁ **6 碼短碼** | 手機 → 教室電腦(最快) | 一邊按「☁ 產生短碼」→ 另一邊按「📥 短碼收羊」打那 6 個字(30 天內有效) |
| 📋 **複製羊圈文字** | 沒網路的時候 | 一邊按「匯出」複製 → 另一邊按「匯入」貼上 |

- 同一隻羊在兩站**長得一模一樣**(外觀是用牠的編號算出來的,不是隨機的)。
- 同一份收兩次**不會變成兩群羊**。
- GPS 抓來的羊在圖鑑上標 🛰️尋羊記,金毛標 ✨,從野獸口中救回來的標 ⚔️。
- 🔒 短碼那條路**不會帶任何地點資訊**(要連地標名字一起搬就用貼文字那條)。

技術面:格式 = localStorage `hfpc-sheepdex-v1`,實作在 `src/sheepdex.js`
(**垂直搬運的複本,正本在 skill `sheepdex-crossite`,請勿就地改**);
短碼中繼站 = `hfpc-sheepdex` Worker + 一顆 KV(私密 repo)。

## 跑起來

```
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/

# 驗收(先 build + npx vite preview --port 4189)
npm run verify:beasts      # 戰鬥六關
npm run verify:landmarks   # 🗺 地標任務 33 項
npm run verify:crossite    # 🐑 跨站搬羊 22 項(打線上網址,不需本機伺服器)

npm run bake:landmarks     # (少用)重烤地標包 —— ⚠ 只烤公開地標,不要烤自己家附近
```

部署(手動,CF Pages):`npx vite build && npx wrangler pages deploy dist --project-name hfpc-sheepflock3d --branch main`
